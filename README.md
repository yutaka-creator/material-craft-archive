# 服と素材の目利き図鑑 - 更新ガイド

## 新しい服を追加するとき

基本的に編集するのは **data.js** です。

data.js の `ITEMS` 配列の中に、新しい服のオブジェクトを1つ追加してください。

### 最低限変更する項目

- `id` : 英数字の一意な名前
- `title` : 商品名
- `brand` : ブランド名
- `brandType` : アウトドア / ヴィンテージ / ファクトリーブランド など
- `category` : トップス / ニット / アウター / パンツ など
- `gender` : メンズ / レディース / ユニセックス
- `size` : サイズ
- `image` : 画像URLまたは画像パス
- `detailUrl` : 詳細ページのパス
- `condition` : USED / VINTAGE など

### 参考価格

```js
price:{
  amount:9790,
  store:"セカンドストリート",
  checked:"2026-09"
}
```

価格が不明な場合は `amount:null` にしてください。

### 目利き評価

```js
scores:{
  material:4,
  durability:5,
  craft:4,
  rarity:2
}
```

各項目は1〜5点です。

- material: 素材の品質・特性
- durability: 耐久性・長く着られるか
- craft: 縫製・作り・ディテール
- rarity: 年代・生産国・仕様などの希少性

**目利き度の★はこの4項目の平均を四捨五入して自動で決まります。**
そのため `mekikiLevel` を手動で書く必要はありません。

## ファイルごとの役割

- **data.js** : 服の商品データを追加・変更する場所
- **script.js** : 検索、フィルター、目利き度自動計算など
- **style.css** : デザイン、カード、スマホ表示
- **index.html** : トップページ全体の構造
- **detail/** : 各商品の詳細ページ
- **dictionary.html** : 素材・用語辞典
- **about.html** : サイトの説明

## 普段の更新で触る場所

新しい服を一覧に追加するだけなら、まず **data.js** を編集してください。
